🩸 Smart Blood Donor Management System

📌 About the Project

Smart Blood Donor Management System is a web-based application developed using Python and Flask. The main purpose of this project is to connect blood donors with patients who require blood during emergencies.

It provides a platform where donors can register and users can access donor-related information easily.

🎯 Objectives

- To simplify the blood donor registration process.
- To connect blood donors with people in need.
- To make blood donor information easier to access.
- To support faster communication during blood emergencies.
- To develop a user-friendly blood donation management platform.

✨ Features

- Donor Registration
- Donor Information Management
- User-Friendly Interface
- Home Page and Navigation
- Blood Request Interface
- Organized Web Application Structure

Note: Features will be updated as development progresses.

⚙️ How to Run the Project

1. Clone the repository:

git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the project folder:

cd SmartBloodDonorManagementSystem

3. Create a virtual environment:

python -m venv venv

4. Activate the virtual environment on Windows:

venv\Scripts\activate

5. Install Flask:

pip install flask

6. Run the application:

python app.py

7. Open the local URL displayed in your terminal in a web browser.
