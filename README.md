🩸 Smart Blood Donor Management System

📌 About the Project

Smart Blood Donor Management System is a web-based application developed using Python and Flask. The main purpose of this project is to connect blood donors with patients who require blood during emergencies.

It provides a platform where donors can register, users can search for donors, and hospitals can participate in blood request management.

🎯 Objectives

- 🩸 To simplify the blood donor registration process.
- 🤝 To connect blood donors with people in need.
- 🔍 To make donor information easily accessible.
- 🚑 To support faster communication during blood emergencies.
- 🏥 To provide hospital registration and integration facilities.
- 💻 To develop a user-friendly blood donation management platform.

✨ Features

- 🩸 Donor Registration
- 📋 Donor Information Management
- 🔍 Find Donors by Blood Group and City
- 🏠 Home Page and Navigation
- 🔐 Admin Login and Dashboard
- 📊 Dynamic Dashboard Statistics
- 🏥 Hospital Registration and Login
- ✅ Hospital Approval Management
- 📝 Blood Request Management
- 📈 Analytics Dashboard
- 🤖 AI Chatbot Integration using Ollama
- 📞 About and Contact Pages

🛠️ Technologies Used

⚙️ How to Run the Project

1. Clone the repository:

git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the project folder:

cd SmartBloodDonorManagementSystem

3. Create a virtual environment:

python -m venv venv

4. Activate the virtual environment (Windows):

venv\Scripts\activate

5. Install the required packages:

pip install flask mysql-connector-python werkzeug requests

6. Start MySQL using XAMPP:

Create a database named "smart_blood_donor" in phpMyAdmin and import the required tables.

7. Run the application:

python app.py

8. Open the application in your browser:

http://127.0.0.1:5000/
